# واژه‌بازی

مجموعه بازی‌های کلمه‌ای فارسی. بازی نخست، **حدس‌واژه** است: کلمه‌ی پنج‌حرفیِ
امروز را در ۶ تلاش پیدا کنید. کلمه‌ی روز برای همه‌ی کاربران در یک روز یکسان است.

ساخته‌شده با React ۱۸ و Vite، بدون هیچ فریم‌ورک CSS یا کتابخانه‌ی UI.
تنها وابستگی‌های اجرایی: `react`، `react-dom` و `react-router-dom`.

## نصب

```bash
npm install
```

## اجرا

```bash
npm run dev      # اجرای محیط توسعه
npm run build    # ساخت نسخه‌ی نهایی در dist/
npm run preview  # پیش‌نمایش نسخه‌ی ساخته‌شده
npm run lint     # بررسی کد با ESLint
```

## امکانات

- تم روشن و تاریک، حالت سخت و حالت رنگ‌کوری (همه ذخیره می‌شوند)
- آمار بازی‌ها، استریک و توزیع حدس‌ها
- اشتراک‌گذاری نتیجه با ایموجی (`navigator.share` و در نبودش کلیپ‌بورد)
- بازیِ نیمه‌کاره با رفرش صفحه سر جایش برمی‌گردد
- همه‌ی اعدادِ نمایشی با ارقام فارسی
- کیبورد مجازی فارسی و پشتیبانی از کیبورد فیزیکی

## ساختار

```
src/
  main.jsx            نقطه‌ی ورود و روتر
  App.jsx             مسیرها، تم و تنظیمات
  styles/global.css   ریست، متغیرهای تم و keyframes
  data/
    words.js          فهرست کلمه‌ها و محاسبه‌ی کلمه‌ی روز
    keyboard.js       چیدمان کیبورد فارسی
  lib/
    persian.js        نرمال‌سازی حروف، ارقام فارسی، تاریخ شمسی
    evaluate.js       ارزیابی حدس و قوانین حالت سخت
    storage.js        لایه‌ی نازک روی localStorage (پیشوند `vajebazi:`)
    share.js          ساخت متن اشتراک‌گذاری
  hooks/
    useLocalStorage.js  stateای که خودش را ذخیره می‌کند
    useSettings.js      تم، حالت سخت، حالت رنگ‌کوری
    useTheme.js         اعمال تم روی <html>
    useWordle.js        تمام state بازی
  pages/              Home، Wordle
  components/         Board، Tile، Keyboard، Key، Header، Modal، Toast و …
    modals/           Help، Stats، Settings، GameOver
```

هر کامپوننت یک فایل `.module.css` هم‌نام کنار خودش دارد.

## افزودن کلمه

کلمه‌ها در [`src/data/words.js`](src/data/words.js) نگهداری می‌شوند:

- `words` — فهرست کاملِ **حدس‌های معتبر**. هر کلمه‌ای که بازیکن مجاز است ثبت کند
  باید اینجا باشد.
- `answers` — زیرمجموعه‌ای از `words` که **کلمه‌ی روز** از آن انتخاب می‌شود.

برای افزودن یک کلمه، آن را به `words` اضافه کنید و اگر می‌خواهید روزی به‌عنوان
کلمه‌ی روز انتخاب شود، به `answers` هم اضافه کنید. نکته‌ها:

- طول هر کلمه باید دقیقاً **پنج حرف** باشد (با `[...word].length` سنجیده می‌شود،
  نه `word.length`).
- املای فارسی استاندارد به‌کار ببرید (`ک` و `ی` فارسی، نه `ك` و `ي` عربی). هنگام
  مقایسه، حروفِ هم‌آوا نرمال‌سازی می‌شوند، پس «آسمان» با ورودی «اسمان» هم پذیرفته
  می‌شود.
- اسم خاص و واژه‌ی توهین‌آمیز اضافه نکنید.
- **ترتیب `answers` را جابه‌جا نکنید** و کلمه‌های موجود را حذف نکنید؛ کلمه‌ی روز
  از روی ایندکس محاسبه می‌شود و هر تغییری در ترتیب، پازلِ روزهای گذشته را عوض
  می‌کند. کلمه‌های تازه را به انتهای فهرست اضافه کنید.

کلمه‌ی روز از تعداد روزهای سپری‌شده از `EPOCH` (در همان فایل) به‌دست می‌آید؛
همین عدد شماره‌ی پازل را هم می‌سازد. `EPOCH` نباید تغییر کند.
