# واژه‌بازی

مجموعه بازی‌های کلمه‌ای فارسی. بازی نخست، **حدس‌واژه** است: کلمه‌ی پنج‌حرفیِ
امروز را در ۶ تلاش پیدا کنید. کلمه‌ی روز برای همه‌ی کاربران در یک روز یکسان است.

ساخته‌شده با React ۱۸ و Vite، بدون هیچ فریم‌ورک CSS یا کتابخانه‌ی UI.
تنها وابستگی‌های اجرایی: `react`، `react-dom` و `react-router-dom`.

## نصب

```bash
npm install
```

## اجرا

```bash
npm run dev         # اجرای محیط توسعه
npm run build       # بررسی تایپ‌ها + ساخت نسخه‌ی نهایی در dist/
npm run preview     # پیش‌نمایش نسخه‌ی ساخته‌شده
npm run lint        # بررسی کد با ESLint
npm run typecheck   # بررسی تایپ‌ها بدون ساخت
npm run test:dates  # بررسی مبنای زمانی و کلمه‌ی روز
npm run word        # دیدن کلمه‌ی روز
npm run words:build # ساختن فهرست حدس‌های معتبر از پکیج
npm run words:check # اعتبارسنجی فهرست‌های کلمه
```

### دیدن کلمه‌ی روز

```bash
npm run word                  # پازل امروز
npm run word -- 2026-07-15    # پازل یک تاریخ مشخص
npm run word -- 42            # پازل شماره‌ی ۴۲
```

## امکانات

- کلمه‌ی روز برای همه‌ی کاربران یکسان است — روزِ بازی به **نیمه‌شب تهران** قفل است،
  نه به ساعتِ دستگاه
- تم روشن و تاریک، حالت سخت و حالت رنگ‌کوری (همه ذخیره می‌شوند)
- آمار بازی‌ها، استریک و توزیع حدس‌ها
- اشتراک‌گذاری نتیجه با ایموجی (`navigator.share` و در نبودش کلیپ‌بورد)
- بازیِ نیمه‌کاره با رفرش صفحه سر جایش برمی‌گردد
- همه‌ی اعدادِ نمایشی با ارقام فارسی
- کیبورد مجازی فارسی و پشتیبانی از کیبورد فیزیکی

## افزودن کلمه

دو فهرست جدا با دو کار متفاوت وجود دارد:

| فهرست | کارش | اندازه | کجا |
|---|---|---|---|
| `words` | حدس‌های معتبر | ~۴۰٬۵۰۰ | `src/data/dictionary.ts` (تولیدشده) |
| `answers` | کلمه‌ی روز | ۳۶۵ | `src/data/words.ts` (دستی) |
| `seedWords` | مکملِ فهرست حدس‌ها | ۲۲۲ | `src/data/seed-words.ts` (دستی) |

### افزودن حدسِ معتبر

فهرست حدس‌ها از پکیج [`an-array-of-persian-words`](https://github.com/pfndesign/an-array-of-persian-words)
تولید می‌شود. این پکیج `devDependency` است و **هیچ‌وقت در کد برنامه import نمی‌شود**؛
اگر می‌شد، حدود ۸۲۷ کیلوبایت فشرده به باندل اضافه می‌کرد.

اگر کلمه‌ای رد می‌شود که باید پذیرفته شود، یعنی پکیج آن را ندارد. آن را به
[`src/data/seed-words.ts`](src/data/seed-words.ts) اضافه کن و بعد:

```bash
npm run words:build   # dictionary.ts را از نو می‌سازد
npm run words:check   # اعتبارسنجی
```

خروجی `dictionary.ts` **در گیت commit می‌شود**، تا بیلد به پکیج وابسته نباشد.

### افزودن کلمه‌ی روز

`answers` در [`src/data/words.ts`](src/data/words.ts) یک **برنامه‌ی زمانی** است:
پازل شماره‌ی N همیشه `answers[N-1]` است.

- **فقط به انتها اضافه کن.** جابه‌جا کردن یا حذف یک کلمه، کلمه‌ی روزهای گذشته را
  عوض می‌کند و تاریخچه‌ی کاربر با واقعیت نمی‌خواند.
- کلمه باید **رایج** باشد؛ جوابی که کسی نمی‌شناسد بازی را غیرقابل‌برد می‌کند.
  فهرست ۴۰ هزارتایی پر از واژه‌ی مهجور و اسم خاص است و برای کلمه‌ی روز مناسب نیست.
- شکل نمایشی را نگه دار (`آسمان`، نه `اسمان`).
- طولش باید دقیقاً پنج حرف باشد (`[...word].length`).

`npm run words:check` اگر ذخیره‌ی کلمه‌ی روز به کمتر از ۳۰ روز برسد خطا می‌دهد.

## کلمه‌ی روز چطور انتخاب می‌شود؟

شماره‌ی پازل از تعداد روزهای سپری‌شده از `EPOCH_DATE` در
[`src/lib/gameDate.ts`](src/lib/gameDate.ts) می‌آید. روزِ مبنا **۱ جولای ۲۰۲۶** است
و پازل شماره‌ی ۱ به‌حساب می‌آید. `EPOCH_DATE` نباید تغییر کند.

روز در منطقه‌ی زمانی `Asia/Tehran` حساب می‌شود، پس کلمه‌ی همه سر نیمه‌شب تهران
عوض می‌شود — مستقل از اینکه کاربر کجای دنیا باشد یا ساعت دستگاهش چه باشد.
